# Blue Note

A complete, dependency-free baby-blue date invitation inspired by a playful pixel love-note flow.

## Run locally

```bash
yarn dev
```

Then open [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Included

- Playful YES/NO interaction with mobile-safe button movement
- Animated baby-blue sky, clouds, stars, parallax, magnetic buttons, and cursor particles
- Respectful “maybe later” ending after the playful refusal sequence
- Celebration particles and optional synthesized sound effects
- Date, activity, and time planner
- Downloadable calendar invite and copyable plan
- Keyboard controls, visible focus states, responsive layouts, and reduced-motion support
- No framework, build process, third-party JavaScript, or runtime package dependency
